# Support

Monkey365 is an open-source project maintained by a solo developer. Community support is provided on a best-effort basis without guaranteed response or resolution times.

## Channels

| Request | Channel |
| --- | --- |
| Get help from the community | [GitHub Discussions](https://github.com/silverhack/monkey365/discussions) |
| Found an issue? Let me know | [GitHub Issues](https://github.com/silverhack/monkey365/issues/new?template=bug_report.md) |
| Suggest an idea or improvement | [GitHub Discussions](https://github.com/silverhack/monkey365/discussions) or the [feature request template](https://github.com/silverhack/monkey365/issues/new?template=feature_request.md) |
| Report a vulnerability or a security-related question | Follow [SECURITY.md](SECURITY.md) |

Before asking for help or filling issues, please search the existing [Issues](https://github.com/silverhack/monkey365/issues), [GitHub Discussions](https://github.com/silverhack/monkey365/discussions) and [documentation](https://silverhack.github.io/monkey365/) to avoid duplicates.

## Information to include

Provide enough sanitised information to reproduce the problem:

- Include clear instructions on how to run and reproduce the issue.
- Monkey365 version and installation method.
- PowerShell version from `$PSVersionTable.PSVersion`.
- Operating system and execution environment, such as workstation or Docker.
- Target cloud type: Azure Public, Azure China, or Azure US Government.
- The command or minimal script that demonstrates the issue.
- Expected and actual behavior.
- Relevant sanitised errors or logs.

Remove tenant names, tenant IDs, subscription IDs, user data, credentials, tokens, certificates, private keys, and other sensitive information. Do not upload complete assessment reports or production logs.

## AI Assisted Reports

If you use AI tools to help prepare a report, you must:

* **Disclose** which AI tools were used and specify what they were used for (analysis, writing the description, explain the issue, etc).
* **Verify** that the issue describes a real, reproducible issue that otherwise meets these reporting guidelines.
* **Avoid** fabricated code, placeholder text, or references to non-existent Monkey365 features.

Reports that appear to be unverified AI output will be closed without response.

## Scope of support

Support for Monkey365 is limited to the resources listed above. It does not include:

- Guaranteed response times or private consulting.
- Incident response or analysis of a specific organization's cloud posture.
- Support for unsupported Monkey365 releases.
- Administration of Microsoft cloud services or third-party products.
- Custom rules, collectors, reports, or deployment pipelines on demand.

Questions with a minimal reproduction, clear environment details, and evidence of prior troubleshooting are more likely to receive a useful response.
